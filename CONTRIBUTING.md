# Contributing to GuardianX

Thank you for your interest in contributing to **GuardianX: AI Home Safety & Care Intelligence**!

## Code of Conduct
Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md) to foster an open and welcoming environment.

## Development Workflow

1. **Fork & Clone**:
   ```bash
   git clone https://github.com/Kathirvel005/GuardianX-AI-Home-Safety-Care-Intelligence.git
   cd GuardianX-AI-Home-Safety-Care-Intelligence
   ```

2. **Install Dependencies**:
   ```bash
   npm run install:all
   ```

3. **Branching**:
   Create a topic branch from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Testing & Code Quality**:
   Always ensure tests pass and code compiles cleanly before opening a pull request:
   ```bash
   npm run test
   npm run build
   ```

5. **Submitting Changes**:
   Push to your branch and open a Pull Request using our [PR Template](.github/PULL_REQUEST_TEMPLATE.md).
